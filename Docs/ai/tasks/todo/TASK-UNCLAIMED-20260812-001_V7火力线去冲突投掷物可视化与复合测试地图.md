# V7：火力线去冲突、投掷物可视化与复合测试地图

## 背景

当前 Tactical Wizard V6 已具备威胁相对移动、协同搜索、Tactical Opportunity、抽象投掷物与近战机会。但实机观察发现：规划器可能把两个火力成员分配到过近或互相遮挡的最终位置。运行时会正确显示 `枪线阻挡 / NO FIRE`，但不会立即把这个状态视为战术计划失败并重新选位。

## 本轮目标

1. 将持续友军枪线阻挡从“提示”升级为“规划失败信号”，触发战术重新选位。
2. 战斗最终站位加入最小间距、计划射界互斥与 Crossfire 角度分离约束，避免两个成员长期叠在同一射线附近。
3. 保留短时间动态穿越/临时遮挡；只有持续阻挡才触发重新规划，避免高频抖动。
4. 强化 flash / frag / smoke 的视觉反馈：投掷轨迹、飞行/落点、效果区和短标签必须可读，并增加可复现的测试入口。
5. 新建更复杂的 V7 测试地图，不改写 V3/V4/V5/V6 的历史回归地图：包含开放场、长射界、巷道、拐角、院落、窄通道、CQB 建筑组和搜索区。
6. 为地图提供可点击测试点/场景预设，便于复现 Crossfire、Lost Contact、Grenade、Close Pressure 等行为。
7. 新增回归测试：持续枪线阻挡必须被打散；交叉火力站位不得互相遮挡；投掷物事件可见；新地图关键区域可达。

## 判定原则

- 两名 AI 距离近本身不一定错误；若是门口、狭窄掩体或短时通过可以接受。
- 若成员被赋予 `base_of_fire / crossfire / hold_cover` 等持续火力职责，却连续多个决策 Tick 因友军阻挡而无法开火，则当前战术位置无效，必须重新规划。
- “架枪”不是“所有人挤在同一条枪线上”。合理架枪必须至少保留有效射界或明确的前后/左右职责。
