## Meaning

“能动”强调主体基于环境与目标进行判断并采取行动的能力。

`Willform` 对应意志、选择并采取行动的能力。品牌层使用 **Willform**，架构哲学中可以使用 **Agency** 描述 Agent 的自主作用能力。

内部设计理念：

> **Agency over scripting.**

它不是对外必须出现的广告语，而是用于提醒开发：Willform 的价值在于组织 Agent 自身的上下文、选择与行动，而不是制造更多硬编码脚本层。
